# Qaiyum Personal Website

A personal résumé website for Qaiyum Hamid, built for CSC574 Assignment 1 using HTML, external CSS and introductory JavaScript.

Includes profile, experience, education, skills, projects, certifications and contact information, with a responsive layout and a dark-mode toggle.

## Files

```text
src/index.html
src/css/style.css
src/images/profile.jpg
src/js/script.js
```

Open `src/index.html` in a browser to view locally. No installation or build step is required.

GitHub Actions deploys the contents of `src/` to GitHub Pages on pushes to `main`, using `.github/workflows/static.yml`.

Live website: [Qaiyum Personal Website](https://qai94.github.io/qaiPersonalWebsite/).
