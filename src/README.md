# Qaiyum Personal Website

A personal résumé website for Qaiyum Hamid, built for CSC574 Assignment 1 using HTML, external CSS and introductory JavaScript.

Includes profile, experience, education, skills, projects, certifications and contact information, with a responsive layout and a dark-mode toggle.

## Files

```text
index.html
css/style.css
images/profile.jpg
js/script.js
```

Open `index.html` in a browser to view locally. No installation or build step is required.

GitHub Pages publishes from the `main` branch and repository root. The website address is https://qai94.github.io/qaiPersonalWebsite/ once deployment is enabled.
